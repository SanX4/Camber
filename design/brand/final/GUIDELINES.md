# Camber — Open C

The rounded C identifies Camber; the separate point represents the incoming
phone connection. Use the same silhouette on Windows and Android.

- Primary teal: #22695D (RGB 34, 105, 93).
- Mint tile: #D9EEE5 (RGB 217, 238, 229).
- Use the black master on light backgrounds and white master on dark backgrounds.
- Keep clear space at least the dot's diameter (36 units on a 256-unit canvas).
- Minimum symbol size: 16 pixels. Use supplied small exports; do not reduce the dot.
- Do not stretch, rotate, add gradients, draw outlines or close the open C.
- Android adaptive foreground is padded to remain inside launcher masks and includes
  a monochrome themed-icon variant. Windows ICO is embedded in the executable.
- UI wordmark uses platform system typography. The symbol itself has no font dependency.
- RGB assets are intended for screens. Print spot-color matching requires a proof;
  no Pantone equivalence is claimed. No trademark clearance is claimed.

Sources: ../camber-master.svg and the supplied monochrome/app icon SVGs.
